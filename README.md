# Java Calculator

A console-based calculator built in Java for a programming course project.

## Features
- Standard mode for addition, subtraction, multiplication, and division
- Scientific mode with sine, cosine, and tangent
- Supports multiple numbers for arithmetic operations
- Validates calculator operators
- Lets the user restart the calculator without reopening the program

## Concepts Used
- Java
- Scanner input
- if / else statements
- while loops
- for loops
- variables and doubles
- Math.sin(), Math.cos(), and Math.tan()

## Run
Compile and run `MyCalculator.java`, then follow the prompts in the console.
